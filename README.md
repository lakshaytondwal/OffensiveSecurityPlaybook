# Offensive Security Playbook

A personal reference archive for offensive security: commands, configs, scripts, and notes I use while learning and practicing penetration testing. It is version-controlled so I can access it from any machine, and it grows as I work through new labs and techniques.

## Contents

| Area | Topics |
|---|---|
| **Active Directory** | Enumeration, attack paths, lateral movement |
| **Network** | Scanning, enumeration, pivoting, WPA2 |
| **Web** | Web application testing workflows |
| **Passwords** | Cracking and credential attacks |
| **Physical Access** | Physical access and local attack notes |
| **Scripting** | Helper scripts and one-liners |
| **Shells** | Reverse shells, shell stabilization, Evil-WinRM |
| **Privilege Escalation** | Linux and Windows |
| **Windows** | Registry, local persistence |
| **C2 & Exploits** | Empire C2, exploit notes |

## Purpose

- Keep essential commands, tools, and configurations in one place
- Provide quick recall during lab work and authorized assessments
- Document techniques as I learn them, in my own words

## About this repository

This is a working notebook, not a tutorial or an original-research showcase. I am still building my skills, so some notes are basic and some are adapted from external sources, which are credited below. Documentation is minimal and some files are specific to particular lab setups.

## Disclaimer

Everything here is for education and authorized security testing only, in lab environments or with explicit written permission. Do not use any of it against systems you do not own or have permission to test. I accept no responsibility for misuse.
